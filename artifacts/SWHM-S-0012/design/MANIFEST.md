## A note on the "Launch Rich Client" control

The mockup shows that label, and the extracted specification says the button generates a JNLP file
and starts Java Web Start. It does not, here — there is no JVM and no second deployable, and the
idea's own Out of Scope excludes a desktop client. The control navigates to the administration
screens this application already serves. Build what the mockup shows; the behaviour behind it is
S2 in the change's planning record.

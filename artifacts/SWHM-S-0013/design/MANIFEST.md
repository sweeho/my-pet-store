# Design references — SWHM-S-0013

Exported from idea **SWHM-I-0007** (Shopping Cart Management), canvas doc version 8, frozen. These files are the authoritative rendering of the cart screen; matching them is implementation work, not design work.

| File                                     | Variant   | Authored size | What it fixes                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------- | --------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wireframe-shopping-cart-populated.html` | wireframe | —             | Column order and the fact that quantity fields are editable and "Update Cart" submits them all at once.                                                                                                                                                                                                                       |
| `wireframe-shopping-cart-empty.html`     | wireframe | —             | The empty state carries the message and nothing else: no rows, no quantity fields, no total, no "Update Cart" button.                                                                                                                                                                                                         |
| `mockup-shopping-cart-populated.html`    | mockup    | 1440×900      | The populated screen — 672px page, "← Continue shopping" back link, "Shopping Cart" heading, item-count subtitle, five columns (Item / Unit Cost / Quantity / Line Total / remove action), per-row `aria-label="Quantity for <itemId>"`, "Update Cart" as the primary action, the Subtotal block, and the zero-quantity hint. |
| `mockup-shopping-cart-empty.html`        | mockup    | 1440×900      | The empty screen — bordered panel, cart glyph, the exact string "Your Shopping Cart is Empty.", the supporting line, and a "Browse the catalog" action.                                                                                                                                                                       |

Both mockups use this repository's own OKLCH-derived token values and Tailwind-equivalent spacing; neither introduces a token, type scale, grid or accessibility standard. See `DESIGN.md` § Tokens.

**The populated mockup prices Parrots at `$350.00`, which is `item.unit_cost` in `catalog/seed.ts`, not the `$599.99` `item.list_price` the catalogue screens display.** That is a deliberate reading of the extracted specification and a known product contradiction — see `openspec/changes/swhm-i-0007-shopping-cart-management/design.md` § Spec discrepancies, S1.
